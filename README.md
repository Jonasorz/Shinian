# Shinian

Shinian 是一个计划部署在个人 VPS 上的自托管卡片笔记与轻量任务管理系统。

项目目标：

- 像 flomo 一样快速记录卡片笔记。
- 提供轻量的任务、提醒和回顾能力。
- VPS 数据库作为唯一主数据源。
- 支持向本地 Obsidian 单向导出 Markdown。
- 未来支持 Android、iOS 及原生分享收件箱。
